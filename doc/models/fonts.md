
# Fonts

Google Fonts for the page.

## Structure

`Fonts`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `heading` | `string` | Required | The headings font. |
| `body` | `string` | Required | The body text font. |

## Example

```ts
import { Fonts } from 'one-thing-sdk';

const fonts: Fonts = {
  heading: 'Playfair Display',
  body: 'Inter',
};
```
